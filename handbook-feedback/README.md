# 📬 Handbook Feedback 收集

## 如何提交 Feedback

**官方渠道（三选一）：**

1. **GitHub**：https://github.com/aiweb3school（找到对应页面的 source 文件，提 PR 或 Issue）
2. **Telegram 社群**：进入官方 Telegram 群，直接 @管理员 或在相关话题下反馈
3. **页面内「编辑此页」按钮**：Handbook 页面底部有直接编辑入口，适合小修正

**提交时建议包含：**
- 所在章节 URL
- 原文内容（截图或引用）
- 问题描述
- 建议改法（如有）
