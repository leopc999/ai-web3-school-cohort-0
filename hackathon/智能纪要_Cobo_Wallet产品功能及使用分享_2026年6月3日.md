音频围绕 Cobo Wallet 的 Hexon 赛道实战展开分享，孟老师介绍了产品底层细节、使用模式、开发工具等内容，并解答了参会者关于产品应用、开发测试等方面的问题，内容如下：

- **产品介绍**

    - **产品环境**

        - 正式环境：官网及 API 有明确地址，APP 上线苹果 App Store 和 Google Play，可在应用商店搜索下载。

    - **产品架构**

        - 后端核心服务：包含钱包交易引擎、风控引擎及审批流。

        - 用户端 AI agent：如 CodeS、Cloud Code 等，可通过官方 Skills 一键安装，Skills 底层调用 CLI，CLI 分 caw 和 tss node 两个 binary。

        - MPC 钱包架构：在用户和服务端各有一片私钥，通过 MPC 技术实现签名，避免任何一方生成完整私钥，保障资产安全。

        - SDK：对 API 进行封装，Python SDK 针对常用 AI 框架封装工具，TS SDK 功能相对较弱。

- **使用模式**

    - **Agent 模式**

        - 安装与操作：复制官网首页 prompt 到 Agent 中可完成 Skills 安装，进而完成钱包安装、账户创建和配对。

        - 钱包功能：未配对时，Agent 可自由操作钱包，但无风控；配对后，Agent 发起交易需提交 packet 经用户确认，手机端可直接转账。

        - 备份注意事项：配对完成后，手机端可通过 iCloud 或本地文件备份，建议做好备份，防止资产丢失。

    - **Developer 模式**

        - CLI：Skills 是对 CLI 用法的封装，运行安装脚本可在本地安装命令，创建钱包时会生成 profile 文件，包含 API key 等信息。

        - API：是 CLI 的更底层，可手动启动 tss node，通过 API 完成创建 API key、钱包、地址、发起配对、提交 packet 等操作。

        - SDK：本质是对 API 的封装，Python SDK 针对常用 AI 框架封装工具，方便 AI agent 开发。

- **应用场景**

    - **AI agent 应用**

        - 支付场景：AI agent 集成区块链钱包后可调用付费 API，进行支付、购买物品、雇佣他人等操作。

        - DeFi 交易：可在 Polymarket 等平台寻找套利机会，自动下注。

    - **Pack 应用**：Pack 是一种定制化策略约束，可设置交易次数、时间等条件，防止 API key 泄露造成危害。

- **问题解答**

    - **鸿蒙适配**：产品无法兼容所有机型，建议使用苹果测试机。

    - **Agent 应用方向**：可根据自身兴趣和技术栈，选择支付、DeFi 交易等方向。

    - **开发环境使用场景**：根据产品形态选择，如提供 web 服务、saas 服务或 APP 可使用 developer 模式。

    - **测试流程**：Web3 测试与 Web2 测试无本质区别，开发环境和正式环境均可测试，开发者环境更友好。

    - **技术支持渠道**：可在 Discord 的 coco organic wallet 群提问，群内有 24 小时值班同事解答问题。
