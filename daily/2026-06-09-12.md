### 踩坑记录

**问题 1：caw CLI 超时 — 需要显式指定 `--api-url`**

- 现象：`caw pact status --pact-id <id>` 直接执行超时
- 原因：CLI 读取 profile credentials 中的 `api_url`（`api-core.agenticwallet.dev.cobo.com`），但 Go binary 在 WSL 下直连 dev API 仍然超时
- 解决：显式传 `--api-url https://api-core.agenticwallet.dev.cobo.com` + 同时设置 `HTTPS_PROXY` + `HTTP_PROXY`
- 💡 关键发现：**必须同时设置 `HTTP_PROXY` 和 `HTTPS_PROXY`**，只设 `HTTPS_PROXY` 不够

**问题 2：transfer 缺少 `src_addr` — 422 Unprocessable Entity（再次确认）**

- 现象：不带 `--src-address` 时，API 返回 422 `body.src_addr: Field required`
- 与 06-08 踩坑相同：dev 环境的 auto-select src address 逻辑未生效
- 解决：显式指定 `--src-address`
- ⚠️ 这是 CAW Dev 环境的已知行为，非 bug — 但文档未明确说明

**问题 3：TSS Node 报 offline**

- 现象：`[DEBUG] TSS Node process alive but backend reports offline, restarting...`
- 影响：首次 CLI 调用会触发 TSS Node 重启，增加约 5~10 秒延迟
- 后续调用恢复正常
- 推测原因：长时间未操作后，TSS Node 心跳超时被后端标记 offline，CLI 唤醒后自动重启
